# Evertrust Growth Engine

Internal build-tracker dashboard for [Evertrust GmbH](https://evertrust-germany.de) - tender lead system for German renewables, construction, industry, and services.

Static HTML. Tactical-telemetry UI in pure black + white. Progress state persists in `localStorage`.

## Live

Live at: https://khadat1506-dotcom.github.io/evertrust-growth-engine/

## What it tracks

- **Dashboard** - hero, build radar, R/E/A/N stage cards, Up Next queue
- **Reach / Engage / Activate / Nurture** - per-stage component checklists with editable task labels
- **Arsenal** - GTA-style weapon wheel of 13 n8n workflows. Hover to preview, click to open in n8n
